* Creating images

* Writing code

### Working Principle:

* Pattern learning

* Adaptability

# **4. Generative Models and Types**

## **What is a Generative Model?**

A generative model learns data distribution and creates new data.

## **Types of Generative Models**

## **1. GAN (Generative Adversarial Network)**

Contains:

* Generator
* Discriminator

Working:
Generator creates data, discriminator checks quality.

Applications:

* Image generation
* Face creation

Advantages:

* High-quality output

Disadvantages:

* Difficult training

---

## **2. VAE (Variational Autoencoder)**

Structure:
Input → Encoder → Latent Space → Decoder → Output

Applications:

* Image reconstruction
* Medical imaging

Advantages:

* Stable training

---

## **3. Transformer Models**

Transformer models use attention mechanisms.

Examples:

* GPT
* BERT

Applications:

* Text generation
* Translation

Advantages:

* Better context understanding

---

## **4. Diffusion Models**

Generate images by removing noise step by step.

Examples:

* Stable Diffusion
* DALL·E

Applications:

* AI image generation

# **7. Architecture of LLMs**

Most LLMs are based on Transformer architecture.

Main Components:

* Tokenization
* Embeddings
* Self-Attention
* Feed Forward Network
* Output Layer

## Transformer Flow:

Input Text → Tokenization → Embedding → Attention → Processing → Output

# **8. How LLMs are Built**

## Step 1: Data Collection

Sources:

* Books
* Websites
* Articles
* Research papers

## Step 2: Data Cleaning

Remove:

* Duplicate data
* Errors

## Step 3: Tokenization

Break text into tokens.

Example:

“I love AI”

→ I | love | AI

## Step 4: Training

Predict next word.

Example:

“The sun rises in the ___”

Answer: east

## Step 5: Fine-Tuning

Specialized for tasks like:

* Medical AI
* Coding AI

## Step 6: Deployment

Released as applications.

Examples:

* Chatbots
* Search tools
